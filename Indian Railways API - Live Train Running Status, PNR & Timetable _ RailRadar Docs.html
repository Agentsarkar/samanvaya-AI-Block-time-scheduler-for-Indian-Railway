Standard Response Envelope#

Every response — success or error — is wrapped in a consistent structure:

JSON200 OK
{  "success": true,  "data": {    "trainNumber": "12952",    "trainName": "MUMBAI RAJDHANI",    "status": "running",    "delayMinutes": 12  },  "meta": {    "traceId": "c4b44917-8e67-4279-b1ff-97f22a5ec2ec",    "timestamp": "2026-08-16T19:00:00+05:30",    "executionTime": 24,    "source": "database"  }}
  • success — Boolean; indicates request success.
  • data — Primary payload containing train, station, or PNR records.
  • meta.traceId — Unique request UUID for support and observability.
  • meta.executionTime — Server processing latency in milliseconds.

API Endpoints#

Trains
GET/v1/trains/{number}

Train Schedule & Timetable API

Full schedule, intermediate halts, running days, and speed sequence.

GET/v1/trains/{number}/live

Live Train Running Status API

Real-time position, delay in minutes, current halt, and diversion alerts.

GET/v1/trains/{number}/route

Train Route Geometry (GIS) API

High-resolution GeoJSON LineString / polyline for map rendering.

GET/v1/trains/{number}/coaches

Train Coach Position & Layout API

Complete rake formation, cabin schematics (LB, MB, UB), and reversals.

GET/v1/trains/{number}/coaches/{station}

Platform Coach Position API

Direction-aware platform coach alignment for specific station halts.

GET/v1/trains/{number}/seats

Train Seat Availability API

14-day rolling seat availability, RAC, and waitlist quotas.

GET/v1/trains/{number}/fare

Train Ticket Fare API

Itemized ticket cost breakdown (base, superfast, GST, tatkal).

GET/v1/trains/between/{from}/{to}

Trains Between Stations API

Direct and connecting trains between two station codes.

PNR Status
GET/v1/pnr/{pnr}

PNR Status API

Booking status, current status, coach & berth assignment, and charting.

GET/v1/pnr/{pnr}/prediction

PNR Confirmation Prediction API

Confirmation probability forecast based on historical trends.

GET/v1/pnr/{pnr}/refund

PNR Cancellation Refund API

Itemized refund amounts, clerkage fees, and cancellation charges.

Stations
GET/v1/stations/{code}/trains

Station Timetable Board API

All scheduled trains halting, originating, or terminating at station.

GET/v1/stations/{code}/live

Live Station Arrival & Departure Board API

Live arrivals and departures in next 2, 4, or 8 hours with live delays.

Lookup & Search
GET/v1/lookup/search/stations

Station Autocomplete Search API

Fast in-memory prefix/substring search across station codes and names.

GET/v1/lookup/search/trains

Train Autocomplete Search API

Fast in-memory search across all train numbers and train names.

GET/v1/lookup/stations

Station Directory Lookup API

Key-value map of station codes to names, coordinates, and zones.

GET/v1/lookup/trains

Train Directory Lookup API

Key-value map of 5-digit train numbers to train names.

GET/v1/lookup/trains/prs

PRS Reserved Trains Directory API

PRS booking attributes, available classes, and run day masks.

GET/v1/lookup/trains/filter

Filter Trains API

Filter active trains by speed category (Superfast, Express) and type.

GET/v1/lookup/trains/categories

Train Categories API

List of active train categories with total train counts.

GET/v1/lookup/trains/types

Train Speed Types API

List of speed and rake classification types with counts.

GET/v1/lookup/trains/ntes

NTES Trains Lookup API

Complete list of active trains tracked in the NTES network.

GET/v1/lookup/stations/ntes

NTES Stations Lookup API

Complete list of railway stations tracked in the NTES network.

GET/v1/lookup/stations/compressed

Compressed Station Lookup Stream API

High-performance newline-delimited CODE|Name text stream.

GET/v1/lookup/trains/compressed

Compressed Train Route Lookup Stream API

High-performance newline-delimited NUMBER|Name|Source|Dest text stream.

GET/v1/lookup/trains/prs/compressed

Compressed PRS Trains Stream API

Bandwidth-optimized stream of all PRS reserved trains.

Suburban / Local Trains
GET/v1/lookup/trains/local

Suburban Local Trains API

Suburban timetable trains for Mumbai, Kolkata, Chennai, and Hyderabad.

GET/v1/lookup/trains/local/cities

Suburban Local Train Cities API

List of supported metropolitan local train cities and counts.
